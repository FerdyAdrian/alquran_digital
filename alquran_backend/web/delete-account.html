Hapus akun dan data

Kamu dapat menghapus akun dari aplikasi: login, buka Setelan → Hapus akun dan data server, lalu konfirmasi.

Jika aplikasi sudah dihapus atau kamu tidak dapat login

  1. Kirim permintaan dari alamat email yang digunakan pada akun.
  2. Tulis subjek “Permintaan hapus akun Al-Qur'an Digital”.
  3. Kami akan memverifikasi kepemilikan akun dan menindaklanjuti dalam 30 hari.
Tulis permintaan penghapusan

Tombol membuka aplikasi email; permintaan baru terkirim setelah kamu menekan Kirim di aplikasi email. Jangan menyertakan password atau kode OTP.

Data yang dihapus

Akun autentikasi Supabase, profil akun, catatan tilawah, jadwal, target khatam, dan pengingat terkait di database. Penghapusan tidak dapat dibatalkan.

Data di perangkat dan penyedia pihak ketiga

Bookmark dan cache bacaan lokal tidak otomatis terhapus. Hapus data aplikasi atau penyimpanan situs untuk membersihkannya. Catatan operasional/keamanan penyedia pihak ketiga mengikuti kebijakan masing-masing. Lihat kebijakan privasi.
